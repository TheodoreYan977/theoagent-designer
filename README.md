# TheoAgent 图文设计器

本地运行的小红书图文排版工具：在浏览器里拖动排版、改字体/颜色，一键导出封面图和图文笔记 PNG。无需联网、无需注册，模板和图片都留在你自己电脑上。

---

## 快速开始（Windows）

**① 安装 Node.js**

去 [nodejs.org](https://nodejs.org/) 下载并安装 **Node.js 20 或更高版本**（LTS 即可）。
装完可以在「命令提示符」里输入 `node -v` 验证，能看到版本号就说明装好了。

**② 启动**

双击项目根目录里的 **`start.bat`**。

- 首次会自动安装依赖（`npm install`），需要等一分钟左右；
- 之后每次启动都很快；
- 启动成功后会自动用浏览器打开 **http://127.0.0.1:8090**。

如果浏览器没有自动打开，手动在浏览器地址栏输入 `http://127.0.0.1:8090` 即可。

**③ 关闭**

关掉那个黑色命令行窗口即可停止服务。

> 不想用 `start.bat`？也可以在项目目录打开命令行，执行：
> ```
> npm install
> node server.mjs
> ```
> 效果完全一样。

## 基本用法

### 新建页面
顶部页面 tab 右侧点 **＋**，选类型（封面 1242×1660 px / 图文笔记 1080×1440 px / 自定义），可填名称 → 创建。
双击 tab 可重命名；点 tab 上的 × 删除（至少保留一页）。

### 编辑元素
- 右侧竖排工具栏：**文字 / 图片 / 矩形 / 吸管**。
- 点选元素后拖动移动；拖四角/四边缩放；拖圆点旋转（按住 Shift 吸附 15°）。
- 属性面板可改：字体、字号、颜色、对齐、行高、加粗、位置、宽高、圆角、边框等。
- 删元素：选中后按 `Delete`，或属性面板「删除」。

### 多选 / 组合 / 复制
- `Shift + 点选` 多选；在空白处 `Shift + 拖动` 框选；
- `Ctrl + C / V / D` 复制 / 粘贴 / 原地复制；
- `Ctrl + G` 组合，`Ctrl + Shift + G` 取消组合。

### 图层面板 & 背景图层
- 图层列表（上为顶层）：拖动排序、👁 显隐、🔒 锁定、双击重命名。
- 列表**最底部**是 **「背景」层**：点它，右侧可改 **页面宽(px) / 高(px)**（点「应用」并确认）和 **底色**（取色器 + 吸管，和元素取色一致）。

### 占位符（内容面板）
- **添加**：点「＋ 添加占位符」，填名称（仅英文/数字/下划线），重名会提示。
- **全局**：勾「全局」→ 确认后该占位符在所有页面可用；取消也要确认。
- **备注**：每个占位符下方可写备注。
- **排序**：块右上角 ↑ / ↓ 调整顺序。
- **重命名**：**双击占位符名称**，全量替换（所有页面/元素里的引用一起改）。
- **删除**：块右上角 ×，会一并清掉元素里的 `{占位符}`（有确认，可 Ctrl+Z 撤销）。
- 内容值是**全局共享**：同一个 `{title_en}` 在封面和图文里填一次、处处一致。

### 保存与导出
- **保存模板**：把当前版式存回 `template.json`。
- **导出 PNG**：弹出大图预览，顶部可切页；右上角：
  - **倍率** `1×` / `2×`（1× = 页面像素尺寸，推荐）；
  - **下载本页** / **下载全部**（下载到浏览器「下载」文件夹）。
- 想分享/留档版式，用顶部 **「模板库」** 存为模板（存到 `templates/`，可再打开/删除）。

## 图片怎么填

**首选：上传** —— 选中图片元素，右侧点「⬆ 上传图片文件」，或把图片直接拖到画布上；图片会存到 `uploads/`，元素自动填好路径。

其余写法：

| 写法 | 预览 | 导出 PNG |
|---|---|---|
| 相对路径 `images/cover.jpg`（放在本文件夹下） | ✅ | ✅ |
| data URL（粘贴 base64） | ✅ | ✅ |
| 绝对路径 `D:\pic\cover.jpg` | ❌（浏览器读不到任意本地路径） | ✅ |

> `uploads/`、`templates/`、`output/` 都已加入 `.gitignore`，不会进版本库。

## 字体

内置 4 款开源字体（SIL OFL 1.1）：**Smiley Sans（得意黑）、Noto Serif、Noto Sans、Noto Sans SC**。
自定义字体：把 `.ttf` 放进 `fonts/`，并在 `server.mjs` 的 `FONTS` 映射里加一行即可。

## 常见问题（Windows）

**双击 `start.bat` 一闪而过 / 没反应**
1. 确认已安装 Node.js 20+（`node -v` 能看到版本号）；
2. 右键「命令提示符」→ 进入项目目录 → 手动执行 `node server.mjs`，看报错信息；
3. 依赖没装成功时，先执行 `npm install`。

**提示端口 8090 被占用**
- 关掉占用 8090 的程序，或换个端口启动：`node server.mjs 8091`，然后访问 `http://127.0.0.1:8091`。

**上传图片失败（Failed to fetch）**
- 说明本地服务没在运行，先启动 `start.bat` / `node server.mjs`，再刷新页面。

**导出 PNG 失败**
- 导出需要本机有 **Chrome 或 Edge**（程序会用它们渲染）。

**导出的图在哪**
- 若点了「下载」，在浏览器「下载」文件夹；
- 程序也会把渲染结果放在 `output/`（`cover.png` / `note.png`）。

**画布找不到了**
- 点顶栏最右的 `⌖`（回到画布中心），或双击画布复位。

## 文件结构

```
theoagent-designer/
├─ start.bat          Windows 一键启动
├─ server.mjs         本地服务（端口 8090）
├─ designer.html      设计器页面（前端）
├─ render.mjs         用 Chrome/Edge 把模板渲成 PNG
├─ template.json      当前模板（排版）
├─ sample.json        内容值（占位符 → 文字/图片）
├─ templates/         模板库（保存的模板）
├─ uploads/           上传的图片
├─ output/            导出的 PNG
└─ fonts/             内置字体
```
